rsynx

Live terminal sharing between two people — no SSH, no public IP, no firewall configuration.

Install

curl -fsSL https://rsynx.ir/i | sh

Windows users can manually download the right binary from the Releases page.

How it works

  • The host creates a new session: rsynx host — a six-digit code and a four-character password are displayed.
  • The guest connects with that same code: rsynx join <code> and enters the password.
  • The host approves or rejects the connection request in their terminal.
  • Once approved, the guest watches the host's terminal live, chats on the same screen, and — if the host approves again — can temporarily take typing control, which the host can revoke at any moment.
